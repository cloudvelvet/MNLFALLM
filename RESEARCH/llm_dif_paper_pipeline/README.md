# LLM-DIF Paper Pipeline

Project: LLM-assisted DIF hypothesis generation in MAPS multicultural panel data.

This folder turns the current LLM-DIF pilot into an academic-paper pipeline. The central rule is:

> LLMs are hypothesis generators, not DIF detectors. All substantive claims require psychometric validation.

## Main Artifacts

- `outputs/llm_dif_paper_pipeline.md`: end-to-end research-to-paper pipeline.
- `outputs/paper_outline.md`: manuscript structure and section-level writing plan.
- `outputs/validation_gates.md`: reviewer-facing guardrails and stop/go criteria.
- `outputs/next_actions.md`: immediate execution checklist.

## Canonical Framing

Do not claim:

- "LLMs detect DIF."
- "LLMs identify biased items."
- "LLMs explain the true cause of DIF."

Use:

- "LLMs generate candidate DIF hypotheses."
- "LLM outputs prioritize item-covariate pairs for follow-up psychometric validation."
- "The study evaluates when LLM rationales align with, or diverge from, empirical DIF evidence."
