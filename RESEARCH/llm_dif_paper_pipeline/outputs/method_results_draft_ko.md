# 연구방법

## 자료와 분석 단위

본 연구는 다문화청소년패널(Multicultural Adolescents Panel Study, MAPS)의 문항을 사용하였다. 분석에는 [MAPS 2기, 사용 wave 기입]의 청소년 및 보호자 응답 문항을 포함하였다. 분석 대상 구인은 문화적응 스트레스, 이중문화수용, 자아존중감, 부모양육, 부모지지, 또래지지, 걱정, 따돌림 등 MAPS에서 반복적으로 사용되는 심리사회적 문항으로 구성하였다. 최종 분석에는 105개 문항이 포함되었다.

분석 단위는 개별 응답자가 아니라 문항-공변량 조합이다. 각 문항은 응답자 유형과 문항 내용에 따라 차별 경험, 한국어 능력, 가구소득, 성별, 연령 공변량과 결합되었다. 단, 보호자 문항에는 청소년 성별 공변량을 적용하지 않는 등 문항과 응답자 유형상 부적절한 조합은 제외하였다. 이 절차를 거쳐 기본 지시문 조건에서는 486개 문항-공변량 조합, 엄격한 DIF 구분 지시문 조건에서는 482개 문항-공변량 조합이 평가에 포함되었다.

## LLM 기반 DIF 후보 가설 생성

대규모 언어모형은 Gemini 2.5 Flash를 사용하였다. 모형에는 각 문항의 구인 정보, 문항 문장, 응답 범주, 공변량 정의를 입력하였다. 모형은 각 문항-공변량 조합에 대해 문턱 DIF 가능성 점수, 예상 방향, 확신도, 판단 근거를 JSON 형식으로 산출하도록 요청받았다. 경험적 DIF 선별 결과, p값, 효과크기, 문항 통계량은 입력에 포함하지 않았다. 따라서 LLM 산출물은 경험적 결과를 보지 않은 상태에서 생성된 후보 가설로 간주하였다.

본 연구는 두 가지 지시문 조건을 비교하였다. 첫째, 기본 지시문은 문항과 공변량 사이의 의미적 관련성을 바탕으로 문턱 DIF 가능성을 평가하도록 구성하였다. 둘째, 엄격한 DIF 구분 지시문은 공변량이 잠재특성의 실제 수준에 미치는 영향과 같은 잠재특성 수준에서의 문항 기능 차이를 구분하도록 더 명시적으로 요구하였다. 이 지시문은 단순한 집단 평균 차이나 일반적 위험요인을 DIF 근거로 사용하지 말고, 문항 표현이나 응답 과정이 문턱 차이로 이어질 수 있을 때 높은 점수를 부여하도록 설계하였다.

모든 LLM 응답은 원자료 형태로 저장하였고, 이후 JSON 파싱을 통해 분석용 표로 변환하였다. 기본 지시문 조건에서는 486개 예측값이 모두 정상 파싱되었다. 엄격한 DIF 구분 지시문 조건에서는 482개 예측값이 정상 파싱되었다.

## 키워드 비교 기준

LLM의 성능을 평가하기 위해 키워드 비교 기준을 함께 사용하였다. 키워드 비교 기준은 문항 텍스트에 공변량 관련 핵심어가 포함되는지를 사전에 정한 규칙에 따라 점수화한 기준이다. 이 기준은 LLM 출력, 경험적 DIF 결과, 응답 분포, 문항 통계량을 사용하지 않는다. 예를 들어 차별 경험과 관련해서는 차별, 무시, 외국인, 따돌림, 놀림과 같은 표면 단서를 사용하였다. 한국어 능력과 관련해서는 한국어, 언어, 한국문화, 외국, 문화와 같은 단서를 사용하였다. 가구소득, 성별, 연령에 대해서도 각각 경제적 조건, 또래 관계 및 외모, 발달 단계 및 진로와 관련된 키워드를 기준으로 삼았다.

키워드 비교 기준은 LLM의 최소 경쟁 기준으로 설정하였다. 이는 LLM이 단순한 단어 일치 이상의 의미 판단을 제공하는지 확인하기 위한 것이다. 특히 차별 경험처럼 표면 단서가 문항에 직접 나타나는 공변량에서는 키워드 기준만으로도 높은 우선순위화 성능이 나올 수 있다.

## 경험적 DIF 선별 결과와 평가 지표

LLM과 키워드 기준의 우선순위화 성능은 잠정적 ordinal DIF 선별 결과와 비교하였다. 이 경험적 선별 결과는 최종적인 DIF 판정이나 참값으로 간주하지 않았다. 본 연구에서는 이를 LLM 산출물과 키워드 기준이 경험적 후보와 어느 정도 정렬되는지를 보기 위한 잠정적 기준으로 사용하였다.

주요 평가지표는 average precision(AP)으로 설정하였다. AP는 경험적 DIF 후보가 점수 순위의 상위에 얼마나 잘 배치되는지를 평가하는 지표다. 본 연구의 목적이 최종 이분 분류가 아니라 후보 우선순위화에 있기 때문에, 정확도보다 AP를 주 지표로 사용하였다. 보조 지표로 precision@5와 precision@10을 함께 보고하였다. 또한 기본 지시문과 엄격한 DIF 구분 지시문 간의 순위 일관성을 확인하기 위해 Spearman 순위상관과 상위 후보 overlap을 계산하였다.

## 판단 근거 코딩

LLM 판단 근거는 별도의 분석 대상으로 다루었다. 자동 규칙 기반 코딩을 통해 각 판단 근거가 어떤 설명 유형을 포함하는지 분류하였다. 코딩 범주는 문항 표현 기반 근거, 응답 과정 기반 근거, 문화·언어 맥락 근거, 검증 가능한 가설 표현, 같은 잠재특성 수준 조건의 명시 여부, 모호한 일반론, 성별·연령 고정관념 가능성, 문항 내용과 직접 관련이 약한 추측, 실제 잠재특성 차이를 DIF로 오인할 가능성 등으로 구성하였다. 이 코딩은 LLM 판단의 타당성을 확정하기 위한 것이 아니라, LLM이 어떤 방식으로 문항-공변량 관계를 구성하는지 확인하기 위한 절차다.

# 결과

## LLM 산출물과 파싱 결과

기본 지시문과 엄격한 DIF 구분 지시문을 사용하여 총 105개 문항에 대한 LLM 산출물을 생성하였다. 기본 지시문 조건에서는 486개 문항-공변량 예측값이 분석에 포함되었고, 이 중 잠정적 경험 DIF 후보는 128개였다. 엄격한 DIF 구분 지시문 조건에서는 482개 예측값이 분석에 포함되었고, 잠정적 경험 DIF 후보는 127개였다. 두 조건 모두 분석 가능한 JSON 형식으로 파싱되었다.

## 전체 우선순위화 성능

전체 수준에서 기본 지시문 조건의 LLM AP는 .382였다. 같은 조합에서 키워드 비교 기준의 AP는 .441이었다. 따라서 기본 지시문 조건의 LLM은 전체적으로 키워드 비교 기준을 넘지 못했다. precision@5는 두 방법 모두 .600이었으나, precision@10은 LLM이 .600, 키워드 비교 기준이 .700이었다.

엄격한 DIF 구분 지시문 조건에서는 LLM AP가 .405로 증가하였다. 이는 기본 지시문 조건보다 높은 값이지만, 같은 조건에서 키워드 비교 기준의 AP(.445)보다는 낮았다. precision@5는 LLM .400, 키워드 비교 기준 .600이었고, precision@10은 LLM .300, 키워드 비교 기준 .700이었다. 이 결과는 엄격한 지시문이 LLM의 전체 AP를 소폭 개선했지만, LLM이 키워드 비교 기준을 일관되게 능가한다는 결론을 지지하지 않는다.

| 지시문 조건 | 분석 조합 수 | 경험 DIF 후보 수 | LLM AP | 키워드 AP | LLM P@5 | 키워드 P@5 | LLM P@10 | 키워드 P@10 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 기본 지시문 | 486 | 128 | .382 | .441 | .600 | .600 | .600 | .700 |
| 엄격한 DIF 구분 지시문 | 482 | 127 | .405 | .445 | .400 | .600 | .300 | .700 |

## 공변량별 성능

공변량별 결과는 LLM의 성능이 공변량의 성격에 따라 달라짐을 보여준다. 차별 경험에서는 기본 지시문 조건의 LLM AP가 .612였고, 엄격한 DIF 구분 지시문 조건에서는 .681로 증가하였다. 같은 공변량에서 키워드 비교 기준의 AP는 .699였다. 즉 엄격한 지시문은 차별 경험 공변량에서 LLM 성능을 키워드 기준에 가깝게 높였지만, 여전히 키워드 기준을 넘지는 못했다.

한국어 능력에서는 기본 지시문 조건의 LLM AP가 .373, 엄격한 DIF 구분 지시문 조건의 LLM AP가 .396이었다. 키워드 비교 기준의 AP는 .575였다. 이 결과는 초기 pilot 분석에서 관찰된 한국어 능력 관련 LLM 우위가 전체 105개 문항으로 확장되었을 때 유지되지 않았음을 보여준다. 전체 문항에서는 한국어, 문화, 언어와 같은 표면 단서가 키워드 비교 기준에 비교적 잘 반영된 것으로 해석할 수 있다.

성별에서는 기본 지시문 조건의 LLM AP가 .340, 엄격한 DIF 구분 지시문 조건의 LLM AP가 .305였다. 키워드 비교 기준의 AP는 .282였다. 두 LLM 조건 모두 키워드 기준보다 높은 AP를 보였지만, 엄격한 지시문에서 성능은 오히려 낮아졌다. 연령에서는 기본 지시문 조건의 LLM AP가 .226, 엄격한 DIF 구분 지시문 조건의 LLM AP가 .253으로 증가하였다. 키워드 기준 AP는 .245와 .252로 거의 같은 수준이었다. 가구소득에서는 경험적 DIF 후보가 3개뿐이었고, LLM과 키워드 기준 모두 낮은 성능을 보였다. 이 공변량의 결과는 강하게 해석하기 어렵다.

| 공변량 | 기본 LLM AP | 기본 키워드 AP | 엄격 LLM AP | 엄격 키워드 AP | 해석 |
|---|---:|---:|---:|---:|---|
| 차별 경험 | .612 | .699 | .681 | .699 | 엄격 지시문에서 개선, 키워드 기준에 근접 |
| 한국어 능력 | .373 | .575 | .396 | .575 | LLM이 키워드 기준보다 낮음 |
| 성별 | .340 | .282 | .305 | .282 | LLM이 높지만 엄격 지시문에서 감소 |
| 연령 | .226 | .245 | .253 | .252 | 엄격 지시문에서 키워드 기준과 유사 |
| 가구소득 | .024 | .135 | .032 | .135 | 경험 후보 수가 적어 해석 제한 |

## 지시문 민감도

기본 지시문과 엄격한 DIF 구분 지시문 사이의 점수 순위는 중간 정도의 관련성을 보였다. 두 조건의 공통 문항-공변량 조합 481개에서 Spearman 순위상관은 .571이었다. 그러나 상위 후보 목록은 크게 달랐다. top-5와 top-10 후보의 overlap은 모두 0이었고, top-20 overlap도 .15에 그쳤다.

이 결과는 LLM 기반 DIF 후보 생성이 지시문 조건에 민감하다는 점을 보여준다. 같은 문항과 공변량을 사용하더라도, 기본 지시문과 엄격한 DIF 구분 지시문은 서로 다른 상위 후보 목록을 만들었다. 따라서 단일 지시문에서 나온 LLM 점수를 안정적인 후보 목록으로 간주하기 어렵다. LLM을 DIF 후보 가설 생성에 사용하려면 지시문 조건을 명시하고, 지시문 변화에 따른 결과 차이를 함께 보고할 필요가 있다.

| 비교 | 공통 조합 수 | 지표 | 값 |
|---|---:|---|---:|
| 기본 지시문 vs 엄격한 DIF 구분 지시문 | 481 | Spearman 순위상관 | .571 |
| 기본 지시문 vs 엄격한 DIF 구분 지시문 | 481 | top-5 overlap | .000 |
| 기본 지시문 vs 엄격한 DIF 구분 지시문 | 481 | top-10 overlap | .000 |
| 기본 지시문 vs 엄격한 DIF 구분 지시문 | 481 | top-20 overlap | .150 |

## 판단 근거 코딩 결과

LLM 판단 근거에 대한 자동 코딩 결과, 엄격한 DIF 구분 지시문은 일부 질적 지표를 개선하였다. 응답 과정 관련 근거는 기본 지시문 조건에서 89.5%였고, 엄격한 DIF 구분 지시문 조건에서 94.8%로 증가하였다. 검증 가능한 가설 표현도 68.9%에서 71.8%로 증가하였다. 반대로 같은 잠재특성 수준 조건을 명시하지 않는 판단 근거는 39.9%에서 30.5%로 감소하였다. 모호한 일반론도 28.2%에서 24.1%로 줄었다.

그러나 엄격한 지시문이 모든 문제를 줄인 것은 아니다. 성별·연령 고정관념 가능성으로 분류된 판단 근거는 기본 지시문 조건에서 16.9%, 엄격한 DIF 구분 지시문 조건에서 19.7%로 증가하였다. 실제 잠재특성 차이를 DIF로 오인할 가능성으로 자동 분류된 사례는 두 조건 모두 낮은 비율이었지만, 엄격한 지시문 조건에서 0.6%에서 1.9%로 증가하였다. 이 비율은 자동 규칙에 따른 보수적 분류이므로 실제 혼동 사례 전체를 포착한다고 보기는 어렵다.

종합하면, 엄격한 DIF 구분 지시문은 LLM 판단 근거에서 응답 과정과 검증 가능한 가설 표현을 늘리고, 같은 잠재특성 수준 조건의 누락을 줄이는 효과를 보였다. 하지만 성별과 연령에 대한 일반적 설명이나 고정관념적 서사는 여전히 남았다. 따라서 지시문을 엄격하게 만드는 것만으로 LLM 판단 근거의 심리측정학적 타당성이 보장되지는 않는다.

| 코딩 범주 | 기본 지시문 | 엄격한 DIF 구분 지시문 |
|---|---:|---:|
| 응답 과정 근거 | 89.5% | 94.8% |
| 검증 가능한 가설 표현 | 68.9% | 71.8% |
| 같은 잠재특성 수준 조건 없음 | 39.9% | 30.5% |
| 모호한 일반론 | 28.2% | 24.1% |
| 성별·연령 고정관념 가능성 | 16.9% | 19.7% |
| 문항 관련성이 약한 추측 | 1.9% | 1.5% |
| 실제 차이를 DIF로 오인할 가능성 | 0.6% | 1.9% |

## 결과 요약

전체 결과는 LLM이 키워드 비교 기준을 일관되게 능가한다는 해석을 지지하지 않았다. 기본 지시문 조건에서 LLM은 전체 AP와 여러 공변량별 AP에서 키워드 기준보다 낮았다. 엄격한 DIF 구분 지시문은 전체 AP와 일부 공변량별 AP를 개선했지만, 여전히 키워드 기준을 넘지는 못했다. 또한 두 지시문 조건의 상위 후보 목록은 크게 달랐다. 이 결과는 LLM 산출물을 DIF 판정 근거로 사용하기 어렵다는 점을 보여준다.

그러나 결과는 LLM 사용 가능성을 전면적으로 부정하지도 않는다. 엄격한 지시문은 일부 성능 지표와 판단 근거의 질을 개선하였다. 따라서 LLM은 단독 판정 도구가 아니라, 키워드 비교 기준, 지시문 민감도 점검, 판단 근거 코딩, 후속 심리측정 검증을 동반할 때 제한적으로 사용할 수 있는 후보 가설 생성 도구로 보는 것이 적절하다.

## 6차년도 단일 wave 민감도 분석

추가 민감도 분석으로 MAPS 2기 6차년도 자료만을 사용하여 동일한 평가를 반복하였다. 이 분석은 1-5차년도 pooled long format 결과가 반복측정 자료 결합 방식에 의해 좌우되는지 확인하기 위한 목적에서 수행하였다. 6차년도 분석에서는 wave 통제항이 필요하지 않으므로, 문항 응답을 척도 점수 proxy와 해당 공변량으로 예측하는 단일 wave ordinal screening 모형을 사용하였다. 이 결과 역시 최종 DIF 판정이 아니라 LLM 및 키워드 기준의 우선순위화 성능을 비교하기 위한 잠정적 기준으로 사용하였다.

6차년도 단일 wave 분석에서도 LLM은 키워드 비교 기준을 넘지 못했다. 기본 지시문 조건의 LLM AP는 .208이었고, 키워드 비교 기준의 AP는 .299였다. 엄격한 DIF 구분 지시문 조건의 LLM AP는 .201이었고, 키워드 비교 기준의 AP는 .302였다. 즉 6차년도 단일 wave 기준에서는 엄격한 지시문이 기본 지시문보다 AP를 개선하지 못했다.

| 지시문 조건 | 분석 조합 수 | 경험 DIF 후보 수 | LLM AP | 키워드 AP | LLM P@5 | 키워드 P@5 | LLM P@10 | 키워드 P@10 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 기본 지시문 | 486 | 70 | .208 | .299 | .600 | .600 | .400 | .300 |
| 엄격한 DIF 구분 지시문 | 482 | 69 | .201 | .302 | .400 | .600 | .200 | .300 |

공변량별 결과도 비슷한 결론을 보였다. 차별 경험에서는 기본 지시문 LLM AP가 .307, 엄격한 지시문 LLM AP가 .260이었고, 키워드 기준 AP는 .370이었다. 한국어 능력에서는 기본 지시문 LLM AP가 .360, 엄격한 지시문 LLM AP가 .328이었으며, 키워드 기준 AP는 .582였다. 성별에서는 LLM이 키워드 기준과 비슷하거나 약간 높은 값을 보였지만, 연령과 가구소득에서는 LLM과 키워드 기준 모두 낮은 성능을 보였다.

| 공변량 | 기본 LLM AP | 기본 키워드 AP | 엄격 LLM AP | 엄격 키워드 AP | 해석 |
|---|---:|---:|---:|---:|---|
| 차별 경험 | .307 | .370 | .260 | .370 | 키워드 기준 우세 |
| 한국어 능력 | .360 | .582 | .328 | .582 | 키워드 기준 우세 |
| 성별 | .248 | .239 | .270 | .239 | LLM이 비슷하거나 약간 높음 |
| 연령 | .050 | .177 | .076 | .198 | LLM과 키워드 기준 모두 낮음 |
| 가구소득 | .057 | .192 | .067 | .192 | LLM과 키워드 기준 모두 낮음 |

6차년도 분석은 주 분석보다 더 단순한 단일 wave 기준을 제공하지만, 일부 공변량의 결측과 표본 축소가 있었다. 특히 청소년 한국어 능력 공변량은 여러 청소년 척도에서 결측이 많았고, 청소년 문화적응 스트레스 척도는 유효 응답자 수가 상대적으로 작았다. 따라서 6차년도 결과는 주 분석을 대체하기보다 민감도 분석으로 해석하는 것이 적절하다. 그럼에도 6차년도 분석에서도 LLM이 키워드 기준을 일관되게 능가하지 못했다는 점은 본 연구의 주요 결론과 일치한다. LLM 산출물은 단독 판정 근거가 아니라, 키워드 비교 기준과 경험적 선별 결과에 비추어 검토해야 할 후보 가설로 다루어져야 한다.
