2. 연구방법
2.1 자료와 분석 단위
본 연구는 MAPS 2기 1-5차년도 자료를 주 분석 자료로 사용하였다. 자료는 청소년과 보호자를 반복 추적한 종단 패널이지만, 본 연구의 목적은 종단 측정동일성 또는 MNLFA를 직접 추정하는 데 있지 않다. 분석의 초점은 경험적 선별 결과를 LLM에 제공하지 않은 상태에서, 후속 검토의 우선순위가 될 문항-공변량 후보를 얼마나 잘 정렬할 수 있는지에 있다. 따라서 1-5차년도 자료는 문항 응답과 공변량 정보를 결합하기 위해 pooled long format으로 구성하였고, 6차년도 자료는 단일 wave 민감도 분석에 사용하였다.
최종 문항 pool은 105개 문항으로 구성하였다. 보호자 문항에는 보호자 공변량을, 청소년 문항에는 청소년 공변량을 적용하였다. 공변량은 차별 경험, 한국어 능력, 가구소득, 성별, 연령이었다. 다만 성별 공변량은 청소년 문항에만 적용하였고, 응답자 유형상 부적절한 문항-공변량 조합은 제외하였다. 이 절차를 거쳐 경험적 screening 파일에는 487개 문항-공변량 조합이 포함되었다. LLM 평가에는 응답 및 파싱이 완료된 조합만 포함하였기 때문에 기본 지시문 조건에서는 486개, 엄격한 DIF 구분 지시문 조건에서는 482개 조합이 분석되었다.

2.2 LLM 기반 검토 후보 설명 생성
LLM에는 Gemini 2.5 Flash를 사용하였다. API 호출에서는 temperature를 0으로 설정하고 응답 형식은 JSON으로 제한하였다. 입력에는 문항 ID, 응답자 유형, 척도/구인 정보, 문항 문장, 응답 범주, 공변량 정의를 포함하였다. 경험적 선별 결과, p값, 효과크기, 문항 통계량, 키워드 점수는 입력하지 않았다. 따라서 LLM 산출물은 경험적 선별 결과를 보지 않은 상태에서 생성된 후보 설명으로 간주하였다. 모든 raw response와 파싱 결과는 별도로 보존하였다.
LLM은 각 문항-공변량 조합에 대해 네 가지 정보를 산출하도록 요청받았다. 첫째, 순서형 DIF 가능성 점수, 둘째, 예상 방향, 셋째, 확신도, 넷째, 판단 근거이다. 출력은 사전에 정의한 JSON schema에 맞추어 제한하였다. 기본 지시문과 엄격한 DIF 구분 지시문의 전문, JSON schema, parsing 규칙은 부록 A와 부록 B에 제시한다.

2.3 키워드 비교 기준
LLM 산출물이 문항의 표면 어휘를 넘어 추가적인 정보를 제공하는지 확인하기 위해 이분형 키워드 비교 기준을 구성하였다. 이 기준은 문항 텍스트에 공변량 관련 핵심어가 하나 이상 포함되는지를 기준으로 점수화하였다. LLM 출력, 경험적 선별 결과, 응답 분포, 문항 통계량은 사용하지 않았다. 다만 이 기준은 무작위 기준이 아니라 연구자가 사전에 구성한 어휘 기반 기준이므로, 차별 경험이나 한국어 능력처럼 표면 단서가 강한 공변량에서는 상당히 강한 비교 기준으로 작동할 수 있다.
차별 경험에는 다른 대우, 편견, 무시, 위축, 사회적 지위, 따돌, 못살게, 외국, 욕, 놀림, 소문을 포함하였다. 한국어 능력에는 한국어, 한국문화, 한국 사람, 한국사람, 한국에, 한국의, 모국, 외국, 문화, 언어를 포함하였다. 가구소득, 성별, 연령에 대해서도 각각 경제적 조건, 또래 관계와 외모, 발달 단계와 진로에 관련된 핵심어를 지정하였다. 키워드 목록은 LLM 결과와 경험적 선별 결과를 보지 않은 상태에서 구성하였다.
점수화는 의도적으로 단순하게 하였다. 각 문항-공변량 조합에 대해 해당 공변량의 키워드가 하나 이상 발견되면 100점, 발견되지 않으면 0점을 부여하였다. 문자열 탐색은 고정 문자열 일치 방식으로 수행하였고, 형태소 분석, 동의어 확장, TF-IDF, 문항 빈도 가중은 사용하지 않았다. 이분형 기준은 동점이 많이 발생하므로, 결과표에서는 키워드 기준의 AP와 P@k를 무작위 동점 해소를 2,000회 반복한 평균으로 제시하였다.

2.4 잠정적 순서형 DIF 선별 기준
LLM과 키워드 기준의 우선순위화 성능은 잠정적 순서형 DIF 선별 결과와 비교하였다. 이 선별 결과는 최종 DIF 판정이나 참값(gold standard)이 아니다. 본 연구에서 이 기준은 LLM 산출물과 어휘 기반 비교 기준이 경험적 선별 신호와 어느 정도 정렬되는지 평가하기 위한 provisional criterion으로 사용된다.
각 문항에 대해 동일 척도의 나머지 문항으로 leave-one-item-out 척도 점수 proxy를 구성하였다. 구체적으로 역채점이 필요한 문항을 정방향으로 변환한 뒤, 같은 응답자 유형, 척도, 개인, wave 안에서 해당 문항을 제외한 평균 응답을 proxy로 사용하였다. 따라서 proxy는 척도별 포함 문항 수에 따라 달라지며, 잠재특성의 직접 추정치가 아니라 관찰 문항에 기반한 matching variable이다.
문항 응답은 proportional-odds 형태의 누적로짓 모형(McCullagh, 1980)에서 순서형 결과변수로 처리하였다. 예측변수에는 leave-one-item-out 척도 점수 proxy, 해당 공변량, wave를 포함하였다. 결측이 있는 행은 문항-공변량 조합별로 제외하였고, 분석 사례 수가 200 미만이거나 응답 범주 수가 3개 미만인 조합, 공변량 또는 wave의 변동이 없는 조합은 제외 규칙에 해당하도록 설정하였다. 주 분석의 screening model은 다음과 같이 요약된다.
문항 응답 = 척도 점수 proxy + 공변량 + wave
공변량 계수는 동일한 척도 점수 proxy 수준에서 공변량에 따라 특정 문항 응답 범주의 선택 경향이 달라지는지를 나타내는 uniform ordinal DIF의 예비 신호로 해석하였다. 본 연구는 nonuniform DIF를 모형화하지 않았고, proportional-odds 가정도 문항별로 별도 검정하지 않았다. p값에는 Benjamini-Hochberg 방식의 FDR 보정을 적용하였다(Benjamini & Hochberg, 1995). FDR 보정은 공변량별로 나누어 적용하지 않고, 유효한 487개 문항-공변량 screening family 전체에 한 번 적용하였다. 주 분석에서는 FDR 보정 p값이 .05 미만이고 절대 계수값이 .20 이상인 조합을 잠정적 순서형 DIF 선별 양성 조합으로 표시하였다. 절대 계수 .20은 누적로짓 척도에서 OR 약 1.22에 해당하는 탐색적 practical nonzero 기준이며, 최종 판정 기준이 아니다.
이 절차에는 명확한 한계가 있다. leave-one-item-out proxy는 잠재특성의 직접 추정치가 아니라 관찰 문항에 기반한 근사치이며, 척도 구조가 다차원적이거나 문항 수가 적을 때 proxy의 의미가 약해질 수 있다. 또한 pooled long format은 wave를 통제하더라도 동일 응답자의 반복 관측 의존성을 완전히 모형화하지 않는다. ordinal logit 계수의 크기도 공변량 스케일링과 문항 응답 범주 수의 영향을 받는다. 따라서 본 연구는 이 기준을 참값으로 명명하지 않고, 민감도 분석에서 practical nonzero 기준(.10, .20, .30), 응답자 단위 cluster-robust 표준오차, 6차년도 단일 wave 분석을 함께 보고하였다.
2.5 평가 지표
주요 평가지표는 average precision(AP)이다. AP는 선별 양성 조합이 점수 순위의 상위에 얼마나 집중되는지를 평가하며, 양성 비율이 낮은 후보 우선순위화 문제에서 유용한 precision-recall 기반 지표이다(Davis & Goadrich, 2006). 본 연구의 목적은 최종 이분 분류가 아니라 전문가 검토 전 후보 우선순위화이므로, 정확도보다 AP를 주 지표로 사용하였다. AP는 양성 비율의 영향을 받기 때문에 결과표에는 선별 양성 비율을 무작위 순위화의 기준값으로 함께 제시하였다. 보조 지표로 precision@5와 precision@10을 보고하였다. AP와 P@k는 기술적 평가 지표이며, 본 원고에서는 별도의 bootstrap 신뢰구간이나 모형 기반 추론검정을 산출하지 않았다.
또한 기본 지시문과 엄격한 DIF 구분 지시문의 산출물이 얼마나 안정적인지 확인하기 위해 Spearman 순위상관과 상위 후보 overlap을 계산하였다. LLM 점수와 키워드 점수에는 동점이 존재할 수 있으므로 top-k overlap은 고정 정렬 규칙에 따른 기술적 지표로 해석하였다. 이 지표는 LLM 산출물이 지시문 조건에 얼마나 민감한지 보여준다.
2.6 판단 근거 코딩과 활용 가능성
LLM 판단 근거는 별도의 분석 대상으로 코딩하였다. 코딩 범주는 응답 과정 기반 근거, 검증 가능한 가설 표현, 같은 잠재특성 수준 조건의 명시 여부, 모호한 일반론, 성별·연령 고정관념 가능성, 문항 내용과 직접 관련성이 약한 추측, 실제 잠재특성 차이를 DIF로 오인할 가능성으로 구성하였다.
자동 규칙 기반 코딩은 판단 근거의 설명 양식을 요약하기 위한 절차이며, 그 자체로 판단 근거의 심리측정학적 타당성을 확정하지 않는다. 자동 코딩의 해석 가능성을 점검하기 위해 지시문 조건, LLM cutoff 70 기준의 TP/FP/FN/TN, 공변량, 고위험 자동 코드가 섞이도록 116개 문항-공변량-지시문 조합을 층화 표집하였다. 코더용 파일에는 문항 원문, 공변량, LLM 판단 근거만 포함하고, empirical screening 결과, LLM 점수, 키워드 점수, 자동 코딩 결과는 별도 key 파일에 보관하였다. 아직 독립 코딩이 완료되지 않은 상태에서는 자동 코딩 결과를 판단 근거의 타당성 증거로 해석하지 않는다.
3. 결과
3.1 LLM 산출물과 파싱 결과
기본 지시문과 엄격한 DIF 구분 지시문을 사용하여 105개 문항에 대한 LLM 산출물을 생성하였다. 경험적 screening 파일에는 487개 문항-공변량 조합이 있었으나, 기본 지시문 조건에서는 age 관련 조합 1개가 LLM 평가 파일에서 누락되어 486개 문항-공변량 예측값이 분석에 포함되었다. 이 중 선별 양성 조합은 128개였다. 엄격한 DIF 구분 지시문 조건에서는 age 관련 조합 5개가 누락되어 482개 예측값이 분석에 포함되었고, 선별 양성 조합은 127개였다.
누락 조합은 대체하지 않았다. 기본 지시문과 엄격한 DIF 구분 지시문을 직접 비교할 때에는 양 조건에 모두 존재하는 481개 공통 조합만 사용하였다. 따라서 분석 조합 수의 차이는 경험적 screening 모형의 제외가 아니라 LLM 응답 및 파싱 가능성의 차이로 해석하였다.
3.2 전체 우선순위화 성능
표 4는 주 분석에서 LLM 점수와 이분형 키워드 비교 기준의 우선순위화 성능을 비교한 결과이다. 기본 지시문 조건에서 분석 가능한 조합은 486개였고, 이 중 잠정적 경험 DIF 후보는 128개였다. 엄격 지시문 조건에서는 482개 조합 중 127개가 잠정적 경험 DIF 후보로 분류되었다. 양성 비율은 두 조건 모두 약 .263이었다.
기본 지시문 조건에서 LLM의 AP는 .382였고, 이분형 키워드 기준의 평균 AP는 .375였다. 엄격 지시문 조건에서는 LLM의 AP가 .405, 키워드 기준의 평균 AP가 .384였다. 즉 전체 AP만 보면 LLM은 이분형 키워드 기준을 소폭 상회하였다. 그러나 차이는 크지 않았고, 상위 5개 및 상위 10개 후보의 정밀도에서는 지시문 조건에 따라 양상이 달랐다.
따라서 주 분석 결과는 LLM이 단순 어휘 기준보다 압도적으로 우수하다는 결론을 지지하지 않는다. 오히려 LLM의 추가 가치는 제한적이며, 키워드 기준처럼 투명한 비교 기준을 함께 두어야 그 의미를 해석할 수 있음을 보여준다.

3.3 공변량별 성능
공변량별 결과는 LLM의 성능이 공변량의 성격에 따라 달라짐을 보여준다(표 5). 차별 경험에서는 기본 지시문에서 LLM AP(.612)가 키워드 기준(.620)과 거의 같았고, 엄격 지시문에서는 LLM AP(.681)가 키워드 기준(.621)을 넘어섰다. 이는 차별 경험처럼 문항 내용과 공변량의 의미가 직접 맞물리는 경우, 엄격한 DIF 구분 지시문이 일부 도움이 될 수 있음을 시사한다.
반면 한국어 능력에서는 두 지시문 조건 모두 키워드 기준이 LLM보다 높았다. 한국어, 문화, 외국과 같은 표면 어휘가 문항에 직접 나타나는 경우가 많았기 때문에, 단순 어휘 기준이 강한 비교 기준으로 작동한 것으로 볼 수 있다. 연령에서도 키워드 기준이 LLM보다 높았다.
성별에서는 기본 지시문 LLM이 키워드 기준보다 약간 높았으나, 엄격 지시문에서는 그 차이가 사라졌다. 가구소득은 잠정적 경험 후보가 세 개뿐이어서 AP가 매우 불안정하므로 강한 해석을 피해야 한다.
전체적으로 공변량별 분석은 LLM의 유용성이 단일 평균값으로 요약되기 어렵다는 점을 보여준다. LLM은 일부 공변량에서 키워드 기준을 보완할 수 있지만, 표면 단서가 강한 공변량에서는 단순 키워드 기준을 안정적으로 넘어서지 못했다.

3.5 판단 근거 코딩 결과
LLM 판단 근거에 대한 자동 코딩 결과, 엄격한 DIF 구분 지시문은 일부 설명 양식 지표의 분포를 변화시켰다. 응답 과정 관련 근거는 기본 지시문 조건에서 89.5%였고, 엄격한 DIF 구분 지시문 조건에서 94.8%로 증가하였다. 검증 가능한 가설 표현도 68.9%에서 71.8%로 증가하였다. 반대로 같은 잠재특성 수준 조건을 명시하지 않는 판단 근거는 39.9%에서 30.5%로 감소하였다. 모호한 일반론도 28.2%에서 24.1%로 줄었다.
그러나 엄격한 지시문이 모든 문제를 줄인 것은 아니다. 성별·연령 고정관념 가능성으로 분류된 판단 근거는 기본 지시문 조건에서 16.9%, 엄격한 DIF 구분 지시문 조건에서 19.7%로 증가하였다. 실제 잠재특성 차이를 DIF로 오인할 가능성으로 자동 분류된 사례는 두 조건 모두 낮은 비율이었지만, 엄격한 지시문 조건에서 0.6%에서 1.9%로 증가하였다. 이 비율은 자동 규칙에 따른 보수적 분류이므로 실제 혼동 사례 전체를 포착한다고 보기는 어렵다.

3.7 Screening 기준 민감도 분석
주 분석의 선별 양성 기준은 FDR 보정 p값 .05 미만과 절대 계수값 .20 이상을 동시에 만족하는 조합이었다. 그러나 이 기준은 최종 DIF 판정이 아니며, 효과크기 기준에 따라 선별 양성 비율과 AP가 달라질 수 있다. 따라서 동일한 LLM 점수와 키워드 점수를 사용하되, 선별 양성 기준만 변경하여 민감도 분석을 수행하였다.
잠정적 경험 DIF 선별 기준을 달리했을 때도 결론의 방향은 크게 달라지지 않았다(표 10). 기준을 완화하거나 강화하면 양성 조합 수와 양성 비율은 변하지만, LLM과 키워드 기준의 상대적 성능은 조건에 따라 달라졌다. 특히 효과크기 기준을 강하게 적용할수록 양성 조합 수가 줄어들기 때문에 AP의 안정성도 함께 낮아진다. 따라서 본 연구의 결과는 특정 임계값 하나에 의존한 확정적 결론이라기보다, 여러 잠정적 기준 아래에서 LLM의 제한적이고 조건부적인 우선순위화 가능성을 확인한 결과로 해석해야 한다.

3.8 6차년도 단일 wave 민감도 분석
추가 민감도 분석으로 MAPS 2기 6차년도 자료만을 사용하여 동일한 평가를 반복하였다. 이 분석은 1-5차년도 pooled long format 결과와 단일 wave 기준의 결과가 같은 방향인지 확인하기 위한 목적에서 수행하였다. 단, 6차년도 분석은 시간 경과, 표본 유지, 결측 구조 변화의 영향을 함께 포함하므로 pooling 방식만을 순수하게 분리한 검증은 아니다. 6차년도 분석에서는 wave 통제항이 필요하지 않으므로, 문항 응답을 척도 점수 proxy와 해당 공변량으로 예측하는 단일 wave 순서형 선별 모형을 사용하였다. 이 결과 역시 최종 DIF 판정이나 종단 모형 검증이 아니라 LLM 및 키워드 기준의 우선순위화 성능을 비교하기 위한 잠정적 기준으로 사용하였다.
6차년도 단일 wave만 사용한 민감도 분석에서는 주 분석과 다른 양상이 나타났다(표 13). 기본 지시문 조건에서 LLM AP는 .208, 이분형 키워드 기준의 평균 AP는 .248이었다. 엄격 지시문 조건에서도 LLM AP는 .201, 키워드 기준의 평균 AP는 .254였다. 즉 6차년도 단일 wave에서는 전체 AP 기준으로 키워드 기준이 LLM보다 높았다.
